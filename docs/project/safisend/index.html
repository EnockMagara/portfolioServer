SafiSend — Restaurant Commerce Platform with a Personalized Menu Recommender

Overview

SafiSend is a production restaurant technology platform I founded and lead as product and engineering lead, deployed at www.safisend.com. Customers scan a QR code to browse, order, and pay from their phone. Underneath the ordering flow I built the platform's machine learning layer: a hybrid recommender that personalizes the menu per diner by combining OpenAI embeddings, collaborative filtering, and a from-scratch FP-Growth market basket miner, plus a GPT-4o Vision OCR pipeline that onboards a restaurant by reading its existing paper menu. The system spans ~144k lines across 57 data models and 156 services, with 859 commits and 68 test suites.

Challenges & Solutions

The hardest problem was recommendation cold start. A diner scanning a QR code is frequently anonymous, has no order history, and will leave within minutes — so there is no time to learn preferences the usual way. I solved it with a five-tier strategy ladder that degrades gracefully (personalized → session learning → cross-restaurant transfer → new customer → anonymous), including a platform-level taste profile that transfers a returning customer's preferences to a restaurant they have never visited. Because every embedding is generated by the same model, "spicy chicken" at one restaurant lands near "fiery wings" at another in the same 1536-dimensional space. That capability had to be built without leaking data across restaurant boundaries: the transfer is confidence-gated, blended at low weight, decayed to zero as local orders accumulate, and opt-out. The other significant challenge was menu onboarding — restaurants arrive with a PDF or a photo, so extraction had to be accurate enough to trust without manual re-entry.

Technical Achievements

  • Hybrid recommender ranking every menu item on five weighted signals — semantic similarity (0.35), collaborative filtering (0.20), behavioral taste profile (0.20), live popularity (0.15), and recency (0.10) — then applying diversity enforcement and context-aware filtering for menu, cart, and checkout surfaces
  • Five-tier cold-start ladder (personalized → session learning → platform transfer → new customer → anonymous) so an anonymous first-time diner still gets a meaningfully ranked menu instead of a default sort
  • Cross-restaurant transfer learning: a platform taste profile aggregates a customer's per-restaurant embeddings weighted by order count and recency into an L2-normalized vector, letting a returning diner get personalized results at a restaurant they have never visited — gated at ≥5 orders across ≥2 restaurants, blended at 30% and decaying to 0% as local history grows, with no cross-restaurant data exposure
  • FP-Growth market basket analysis implemented from scratch in dependency-free JavaScript (FP-tree construction, header tables with node links, recursive conditional pattern base mining) following Han, Pei & Yin (2000), unit tested and mining frequent itemsets and association rules scored by support, confidence, lift, and conviction
  • Semantic embedding engine over OpenAI text-embedding-3-small: 1536-dimensional item and customer vectors, customer vectors computed as L2-normalized weighted averages of ordered items, cosine similarity matching, batch generation, and an LRU-style cache with hit/miss instrumentation
  • Real-time session learning that blends a live session embedding with the stored customer vector (70/30), so recommendations adapt to what the diner is browsing within a single sitting
  • GPT-4o Vision menu OCR with a multi-pass accuracy strategy: Sharp-based image preprocessing, a first extraction pass, then a focused second pass that re-analyzes only items scoring below the 0.85 confidence threshold before merging results — plus currency detection, category inference, dietary attribute inference, and confidence scores that route uncertain items to human review
  • Closed-loop recommendation analytics: impression, click, and add-to-cart events are logged per surface with the originating strategy and score, giving compound-indexed data to evaluate which recommendation sources actually convert
  • Upsell engine classifying premium upgrades, add-ons, and meal completers scored on embedding similarity (0.50), price uplift (0.30), and co-purchase rate (0.20), precomputed by a scheduled mining job
  • Production commerce foundation: QR-to-order with no app install, real-time split billing, WhatsApp Business API notifications, M-Pesa payment callbacks and reconciliation, live kitchen dashboard, Dockerized services behind Nginx, and JMeter load testing to 500+ concurrent users
