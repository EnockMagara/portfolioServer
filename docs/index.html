How I work

Boundaries are enforced, not remembered.

A tenant is a property of the verified actor. Nothing reads a shop id from a body or a query, an ESLint rule fails any read of the header outside the one resolver, and a guard on every model refuses a filter that names another shop.

Numbers come from tools, never from a model.

A model chooses which tools to call and how to phrase the answer. Every figure it reports is a tool result, cited to the rows that produced it. High-risk actions become proposals a person approves under their own authority.

Every rule has a check that only gets stricter.

Tenancy, layering, logging, silent failures, secrets, copy and design each have a baseline file in CI. A pull request can lower the count. None can raise it.

Money is append-only, then reconciled.

Ledger rows are never edited. Settlements are polled and matched to sales, payouts are verified against the processor, and every deploy that touches money is logged with how to check it.
